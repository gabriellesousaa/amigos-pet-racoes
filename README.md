# Amigos Pet Rações 🐾

Projeto desenvolvido para o módulo de Desenvolvimento Web Responsivo do curso de Análise e Desenvolvimento de Sistemas.

## 📌 Sobre o projeto

O projeto consiste no desenvolvimento de uma página responsiva para a loja Amigos Pet Rações. A página apresentará informações sobre a empresa, produtos, promoções e formas de contato.

O site será adaptado para diferentes tamanhos de tela, como computadores, tablets e celulares.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## 📂 Estrutura do projeto

- `index.html`: estrutura principal da página
- `css/`: arquivos de estilização
- `img/`: imagens utilizadas no site
- `js/`: arquivos JavaScript

## ▶️ Como executar o projeto

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.
4. No Visual Studio Code, também é possível clicar em **Go Live**.
